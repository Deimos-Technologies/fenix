# 📮 help/ — skrzynka na dokumenty PISANE DLA AI

Tu lądują pliki-konteksty i briefy adresowane do asystentów AI (Claude, GPT,
Gemini, Grok, Qwen, Kimi…). Zasada: **jedna ześła = jeden plik**, numerowane
`NN_temat.md`, po polsku (można z angielskim TL;DR na górze).

Konwencja:
- pliki są **kroniką dla AI**, nie dokumentacją użytkową (ta mieszka w `docs/`);
- każdy plik zaczyna się od: data, stan projektu (commit/liczby audytu),
  po co ten dokument istnieje;
- gdy dokument starzeje się (zmiana architektury) — dopisać nowy numer,
  NIE nadpisywać starego (historia jak FenixRap-vXXX).
